## Target audience and content

| Question | Answer |
| --- | --- |
| Target age groups | **18 and over** only |
| Could the app unintentionally appeal to children? | **No** (plain text vocabulary tool, no characters, no game mechanics aimed at children) |
| Store listing shown to children? | Not applicable (no under-13 age group selected) |

Why 18+: the AI features send user text to the Google Gemini API, whose terms require users to be
18 or older, and the privacy policy says the app is not for under-18s (section "Çocuklar").
Choosing an under-18 group would also bring the app under the Families policy (no Gemini free
tier for children's data, teacher-approved programme rules), which Engapp does not meet.

## AI-generated content

Engapp generates content with AI (meanings, example sentences, memory hints, theme groups, the
weekly report comment, and in v0.4 word images). Play's AI-generated content policy asks for:

- **No prohibited content:** prompts ask only for dictionary-style output on the word given; the
  output is validated against a schema on the server before it is stored (`supabase/functions/_shared/*`).
- **A way for users to report or flag offensive AI output inside the app:** every AI example
  sentence and memory hint can be hidden or marked as not useful (`content_feedback`), and every
  meaning can be edited before and after it is added. **Gap to note:** this feedback hides the
  item for the user and is stored with their account; there is no separate "report to the
  developer" button. If the review asks for one, add a "Bildir" action that writes the same
  feedback with a report flag (deferred, ADR 0035).
